# ยินดีต้อนรับสู่ Thoth

Thoth เก็บโน้ตของคุณเป็นไฟล์ Markdown ธรรมดา ในโฟลเดอร์ที่คุณเลือกเองบนคอมพิวเตอร์เครื่องนี้
ไม่ต้องมีบัญชี ไม่ต้องใช้คลาวด์ แอปอื่นก็เปิดไฟล์เดียวกันนี้ได้ คุณเองก็เช่นกัน
หน้านี้มีบล็อกทุกแบบที่ Thoth มี พร้อมวิธีสร้างแต่ละแบบ จะแก้ไขก็ได้ หรือลบทิ้งเมื่อไม่ต้องการแล้ว

พิมพ์ `/` ที่บรรทัดว่างเพื่อเปิดเมนูบล็อก หรือลากที่จับทางซ้ายของบล็อกเพื่อย้าย กด Cmd/Ctrl+Shift+E เพื่อสลับระหว่างโหมดบล็อกกับโหมดข้อความล้วน (ตัว Markdown เอง)

## หัวข้อ

# หัวข้อ 1

`/h1` หรือพิมพ์ `#` แล้วเว้นวรรคที่ต้นบรรทัด

## หัวข้อ 2

`/h2` หรือ `##` แล้วเว้นวรรค

### หัวข้อ 3

`/h3` หรือ `###` แล้วเว้นวรรค

## รายการ

- รายการแบบจุด: `/bullet` หรือ `-` แล้วเว้นวรรค
- Enter เริ่มรายการถัดไป ส่วน Enter ที่รายการว่างจะจบรายการ

1. รายการแบบตัวเลข: `/numbered` หรือ `1.` แล้วเว้นวรรค
2. ตัวเลขจะเรียงต่อกันเอง

- [ ] รายการสิ่งที่ต้องทำ: `/todo` หรือ `[]` แล้วเว้นวรรค
- [x] คลิกที่ช่องเพื่อทำเครื่องหมายว่าเสร็จแล้ว

## บล็อกพับได้

> [!toggle]- บล็อกพับได้: คลิกที่ลูกศรเพื่อเปิด
> สิ่งที่อยู่ข้างในจะซ่อนไว้จนกว่าคุณจะเปิด สร้างได้ด้วย `/toggle` หรือ `>>` แล้วเว้นวรรค

## กล่องข้อความเด่น

> [!note] หมายเหตุ
> กล่องข้อความเด่นทำให้ข้อความสะดุดตา: `/callout` ใน Markdown คือคำพูดอ้างอิงที่ขึ้นต้นด้วย `[!note]`

> [!tip] เคล็ดลับ
> เปลี่ยนคำในวงเล็บเพื่อเปลี่ยนแบบ: `[!tip]`

> [!warning] คำเตือน
> `[!warning]` ใช้กับสิ่งที่ต้องระวัง

> [!danger] อันตราย
> `[!danger]` ใช้กับสิ่งที่ย้อนกลับไม่ได้

> [!example] ตัวอย่าง
> `[!example]` แยกตัวอย่างออกมาให้เห็นชัด

## คำพูดอ้างอิง

> คำพูดอ้างอิง: `/quote` หรือ `>` แล้วเว้นวรรค

## โค้ด

```js
// บล็อกโค้ด: /code หรือพิมพ์ backtick สามตัวแล้วเว้นวรรค
const greeting = "สวัสดีจาก Thoth";
```

## เส้นคั่น

เส้นคั่น: `/divider` หรือ `---` ที่บรรทัดว่าง

## ตาราง

| บล็อก | Markdown |
| --- | --- |
| ตาราง | แถวของช่องที่คั่นด้วยขีดตั้ง |
| หัวตาราง | แถวแรก โดยมี `---` อยู่ใต้ |

ตารางเขียนในโหมดข้อความล้วน: หนึ่งแถวต่อหนึ่งบรรทัด และคั่นช่องด้วย `|`

## รูปแบบข้อความ

เลือกข้อความเพื่อเปิดแถบเครื่องมือ หรือใช้ปุ่มลัด:

- **ตัวหนา**: Cmd/Ctrl+B หรือ `**ตัวหนา**`
- *ตัวเอียง*: Cmd/Ctrl+I หรือ `*ตัวเอียง*`
- <u>ขีดเส้นใต้</u>: Cmd/Ctrl+U หรือ `<u>ขีดเส้นใต้</u>`
- ~~ขีดฆ่า~~: Cmd/Ctrl+Shift+S หรือ `~~ขีดฆ่า~~`
- `โค้ด`: Cmd/Ctrl+E หรือคำที่อยู่ระหว่าง backtick
- ==ไฮไลต์==: Cmd/Ctrl+Shift+H หรือ `==ไฮไลต์==`
- <span data-color="blue">สีตัวอักษร</span>: ปุ่มสีในแถบเครื่องมือ
- [ลิงก์ไปยังหน้าเว็บ](https://commonmark.org/help/): Cmd/Ctrl+Shift+K หรือ `[ข้อความ](ที่อยู่)`
