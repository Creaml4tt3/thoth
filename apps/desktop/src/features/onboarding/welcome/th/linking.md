# การลิงก์หน้า

หน้าต่าง ๆ ลิงก์ถึงกันด้วยชื่อ พิมพ์ `[[` แล้วเริ่มพิมพ์ชื่อหน้าเพื่อเลือกจากรายการ

## แบบของลิงก์

- ลิงก์ไปยังหน้า: [[ยินดีต้อนรับสู่ Thoth]]
- ลิงก์ไปยังหน้าในโฟลเดอร์: [[เริ่มต้นใช้งาน/แป้นพิมพ์ลัด]]
- ลิงก์ที่มีข้อความของตัวเอง (ชื่อแทน): [[ยินดีต้อนรับสู่ Thoth|หน้าแรก]]
- ลิงก์ไปยังหัวข้อในอีกหน้า: [[ยินดีต้อนรับสู่ Thoth#กล่องข้อความเด่น]]
- ลิงก์ไปยังหัวข้อในหน้านี้: [[#ลิงก์ย้อนกลับ]]
- ลิงก์ Markdown ไปยังหน้า แบบที่แอปอื่นเขียน: [ยินดีต้อนรับสู่ Thoth](%E0%B8%A2%E0%B8%B4%E0%B8%99%E0%B8%94%E0%B8%B5%E0%B8%95%E0%B9%89%E0%B8%AD%E0%B8%99%E0%B8%A3%E0%B8%B1%E0%B8%9A%E0%B8%AA%E0%B8%B9%E0%B9%88%20Thoth.md)
- ลิงก์ไปยังหน้าเว็บ: [คู่มือ CommonMark](https://commonmark.org/help/)

ใน Markdown ลิงก์คือชื่อหน้าในวงเล็บเหลี่ยมคู่: `[[หน้า]]` `[[หน้า|ข้อความ]]` `[[หน้า#หัวข้อ]]`

## การฝัง

การฝังบอกว่าหน้านั้นเป็นส่วนหนึ่งของที่นี่ เขียนโดยมี `!` นำหน้า: `![[หน้า]]`

## ลิงก์ย้อนกลับ

ทุกหน้ามีรายชื่อหน้าที่ลิงก์มาหา อยู่ใต้หน้านั้น: เปิด [[ยินดีต้อนรับสู่ Thoth]] แล้วจะเห็นหน้านี้อยู่ที่นั่น เมื่อเปลี่ยนชื่อหรือย้ายหน้า Thoth จะแก้ลิงก์ที่ชี้มาหาให้เอง
