# แป้นพิมพ์ลัด

ปุ่มลัดที่ใช้บ่อยที่สุด กด Cmd/Ctrl+/ เพื่อดูปุ่มลัดทั้งหมด และกด Cmd/Ctrl+K แล้วพิมพ์ `>` เพื่อหาคำสั่งด้วยชื่อ

## ใช้ได้ทุกที่

| ทำอะไร | macOS | Windows และ Linux |
| --- | --- | --- |
| ค้นหา และคำสั่งหลัง `>` | `Cmd+K` | `Ctrl+K` |
| ปุ่มลัดทั้งหมด | `Cmd+/` | `Ctrl+/` |
| หน้าใหม่ | `Cmd+N` | `Ctrl+N` |
| โฟลเดอร์ใหม่ | `Cmd+Shift+N` | `Ctrl+Shift+N` |
| หน้าแรก | `Option+Shift+H` | `Alt+Shift+H` |
| ซ่อนหรือแสดงแถบด้านข้าง | `Cmd+\ / Cmd+Backslash` | `Ctrl+\ / Ctrl+Backslash` |
| เพิ่มในรายการโปรด | `Cmd+D` | `Ctrl+D` |
| การตั้งค่า | `Cmd+,` | `Ctrl+,` |
| ธีมถัดไป | `Cmd+Shift+L` | `Ctrl+Shift+L` |
| ถามผู้ช่วย เมื่อตั้งค่าไว้แล้ว | `Cmd+J` | `Ctrl+J` |

## แท็บ

| ทำอะไร | macOS | Windows และ Linux |
| --- | --- | --- |
| แท็บใหม่ | `Cmd+T` | `Ctrl+T` |
| ปิดแท็บ | `Cmd+W` | `Ctrl+W` |
| แท็บถัดไป | `Ctrl+Tab` | `Ctrl+Tab` |
| ไปที่แท็บ 1 ถึง 9 | `Cmd+1–9` | `Ctrl+1–9` |
| แบ่งไปทางขวา | `Cmd+Option+Backslash` | `Ctrl+Alt+Backslash` |
| ปักหมุดแท็บ | `Option+Shift+P` | `Alt+Shift+P` |

## การเขียน

| ทำอะไร | macOS | Windows และ Linux |
| --- | --- | --- |
| บันทึกทันที | `Cmd+S` | `Ctrl+S` |
| โหมดบล็อกหรือข้อความล้วน | `Cmd+Shift+E` | `Ctrl+Shift+E` |
| เมนูบล็อก | `Cmd+Option+M` | `Ctrl+Alt+M` |
| ย้ายบล็อกขึ้นหรือลง | `Option+Shift+↑ / ↓` | `Alt+Shift+↑ / ↓` |
| ตัวหนา | `Cmd+B` | `Ctrl+B` |
| ตัวเอียง | `Cmd+I` | `Ctrl+I` |
| ขีดเส้นใต้ | `Cmd+U` | `Ctrl+U` |
| ขีดฆ่า | `Cmd+Shift+S` | `Ctrl+Shift+S` |
| โค้ด | `Cmd+E` | `Ctrl+E` |
| ไฮไลต์ | `Cmd+Shift+H` | `Ctrl+Shift+H` |
| ลิงก์ | `Cmd+Shift+K` | `Ctrl+Shift+K` |
