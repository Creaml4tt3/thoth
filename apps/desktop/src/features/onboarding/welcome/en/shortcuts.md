# Keyboard shortcuts

The keys that matter most. Cmd/Ctrl+/ lists every shortcut, and Cmd/Ctrl+K then `>` finds every command by name.

## Everywhere

| What it does | macOS | Windows and Linux |
| --- | --- | --- |
| Search, and commands after `>` | `Cmd+K` | `Ctrl+K` |
| All keyboard shortcuts | `Cmd+/` | `Ctrl+/` |
| New page | `Cmd+N` | `Ctrl+N` |
| New folder | `Cmd+Shift+N` | `Ctrl+Shift+N` |
| Home | `Option+Shift+H` | `Alt+Shift+H` |
| Hide or show the sidebar | `Cmd+\ / Cmd+Backslash` | `Ctrl+\ / Ctrl+Backslash` |
| Add to Favorites | `Cmd+D` | `Ctrl+D` |
| Settings | `Cmd+,` | `Ctrl+,` |
| Next theme | `Cmd+Shift+L` | `Ctrl+Shift+L` |
| Ask the assistant, when it is set up | `Cmd+J` | `Ctrl+J` |

## Tabs

| What it does | macOS | Windows and Linux |
| --- | --- | --- |
| New tab | `Cmd+T` | `Ctrl+T` |
| Close tab | `Cmd+W` | `Ctrl+W` |
| Next tab | `Ctrl+Tab` | `Ctrl+Tab` |
| Go to tab 1 to 9 | `Cmd+1–9` | `Ctrl+1–9` |
| Split right | `Cmd+Option+Backslash` | `Ctrl+Alt+Backslash` |
| Pin tab | `Option+Shift+P` | `Alt+Shift+P` |

## Writing

| What it does | macOS | Windows and Linux |
| --- | --- | --- |
| Save now | `Cmd+S` | `Ctrl+S` |
| Blocks or Plain mode | `Cmd+Shift+E` | `Ctrl+Shift+E` |
| Block menu | `Cmd+Option+M` | `Ctrl+Alt+M` |
| Move a block up or down | `Option+Shift+↑ / ↓` | `Alt+Shift+↑ / ↓` |
| Bold | `Cmd+B` | `Ctrl+B` |
| Italic | `Cmd+I` | `Ctrl+I` |
| Underline | `Cmd+U` | `Ctrl+U` |
| Strikethrough | `Cmd+Shift+S` | `Ctrl+Shift+S` |
| Code | `Cmd+E` | `Ctrl+E` |
| Highlight | `Cmd+Shift+H` | `Ctrl+Shift+H` |
| Link | `Cmd+Shift+K` | `Ctrl+Shift+K` |
