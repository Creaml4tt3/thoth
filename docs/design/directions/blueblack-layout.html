@Launch notesAsk…
  • Inset layout. The sidebar sits on the ground (#00001C at night, papyrus in daylight) and the page is a raised card with rounded corners, the way Notion Calendar, Arc and Linear frame content. Depth comes from one tonal step, not borders or glows.
  • Pill tabs on the ground instead of a tab strip; the active tab is the only one with a card behind it.
  • Ask beside the page. The agent opens as a side panel for this page, not only in a separate Hub. Its change shows on the page as a Moon highlight with a "Proposed by" label (words, not only colour) before you apply it.
  • Sidebar is shorter: Search and New page become one pill row; Home, Today and Agents are pinned; a live line at the bottom says what an agent is doing right now.
