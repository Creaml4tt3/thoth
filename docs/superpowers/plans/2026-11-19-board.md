# Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Board view in the desktop app: an Overview of every page of a Private Space and the user's own boards (`.canvas` files), drawn as sticky notes joined by string; drawing string adds a real link.

**Architecture:** Pure data modules in `@thoth/app-ui/board/` (graph data, JSON Canvas read/merge/write, layout, undo) are tested without a DOM. A `BoardView` renders notes as DOM buttons and strings as one SVG layer inside a CSS-transformed plane. The desktop app wires it to the vault (`Vault.graph()`, compare-and-swap writes, the Connections `linkText`) and adds a `{ kind: "board" }` tab.

**Tech Stack:** React 19, TypeScript, `d3-force` (new, ISC), Vitest + Testing Library, SQLite index in `@thoth/local-store`.

**Spec:** `docs/superpowers/specs/2026-11-19-settings-select-board-design.md` (Part 3). Mockup: `.superpowers/brainstorm/11459-1795092475/content/board-look-v2.html`, option B.

## Global Constraints

- Private Spaces in the desktop app only; no Board for workspaces or the web app.
- Boards are JSON Canvas 1.0 `.canvas` files in the Space. Thoth writes only `file` nodes it owns; strings are **never** stored as edges. Unknown nodes, edges and fields are kept byte-for-meaning (round trip loses nothing).
- Note on screen at 100 %: ≈160×120 px. Title bold; first line muted, two lines max; up to 3 tag chips (Moon soft wash `--thoth-accent-soft` / `--thoth-accent-ink`); orange push pin.
- Note colour: its folder's colour from the order record (`colors`), else the nearest coloured parent folder's, else cream.
- Click selects; double-click or Enter opens; Cmd/Ctrl+click opens in a new tab. Selected note's strings turn Moon (`--thoth-moon`; slight glow in dark mode).
- Zoom 10 %–200 %. Arrow keys move a selected note 8 px (Shift: 40 px).
- Drag lifts the note (larger shadow, ~3° tilt) and it settles with a short wobble; reduced motion removes tilt, wobble, glow and animated string.
- Overview: d3-force, runs to rest once (in a worker if > 50 ms), then still; positions cached for the session only. Below 40 % zoom notes draw as coloured squares in one SVG.
- Board saves debounced 500 ms; on conflict re-read, re-apply only Thoth's own changes by node id, write again.
- Suggestions: at most 12 unpinned pages linked to or from pinned pages.
- Drawn string writes exactly one link line at the end of the source page, spelled by `linkText` (`apps/desktop/src/features/editor/PrivateConnections.tsx:21`), through compare-and-swap; on conflict re-read and retry once, then tell the user.
- Undo/redo (Cmd/Ctrl+Z, Shift+Cmd/Ctrl+Z) covers moves, pins, removals and drawn links for the tab's life; a drawn link is undone only if it is still the last line and unchanged.
- ADR-0056 "Board" amends ADR-0045's "no graph view". New strings English + Thai (`// REVIEW`). `d3-force` added to THIRD-PARTY-LICENSES.
- `pnpm check` passes at the end of every task.

## Review Focus

- A `.canvas` made by Obsidian with `text`, `link`, `group` nodes and edges: open, move one note, save → every other node, edge and unknown field is unchanged. Test in Task 2.
- A page pinned to a board is renamed or moved in the sidebar → the board still shows it (path rewritten), not a "missing" note. Test in Task 3.
- Drawing string from a page that is open in an editor tab with unsaved edits: the edits are flushed first and kept; the link lands after them. Test in Task 7.
- A Space with 2,000 pages: the Overview opens without freezing (layout off the main thread, squares below 40 %). Test in Task 5 (timing guard on the layout function) and Task 6 (only notes in view are DOM).
- Thai titles wrap inside a note without overflowing it. Test in Task 6 (note has `overflow-wrap`/line clamp styles; snapshot of computed class).
