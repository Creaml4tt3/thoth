# Security

## Reporting a problem

Please email **security@thothnotes.com** if you find a security problem in Thoth:
the desktop app, the web client at thothnotes.com/app/, the workspace server
(including the demo server at api.thothnotes.com) or the website.

Please include:

- what is affected, and the version (Settings → About in the app);
- the steps to reproduce it, or a proof of concept;
- what someone could do with it.

Please do not open a public issue, post about it, or test against other
people's accounts or workspaces. Use your own account and workspaces only, and
do not run automated scans that could slow the demo server down for others.

We will confirm we got your report, keep you updated while we work on a fix,
and credit you in the release notes if you would like.

## Supported versions

Fixes go into the latest release. Please check that the problem is still there
in the latest version before you report it.
